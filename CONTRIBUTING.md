# Contributing

This file will describe the plugin folder structure, the manifest field
reference, dependency rules, pre-PR checks, and the PR checklist. The
top-level folders a contributor works in today are `plugins/` (the four
installable plugins), `docs/` (contribution/security/release documentation),
`scripts/` (build and release tooling), and `site/` (the GitHub Pages catalog
SPA). Full content: Phase 2.
